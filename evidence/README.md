# XPRIZE Evidence Folder

The hackathon is judged on real business operation, so evidence should be captured continuously instead of reconstructed at the end.

## Folder Responsibilities

- `revenue/` - Stripe exports, paid invoices, bank deposits, P&L, signed purchase orders, and revenue screenshots.
- `customers/` - customer contact list, testimonials, feedback notes, permissions, and case study source material.
- `expenses/` - Google Cloud billing, Gemini/Vertex AI usage, marketing spend, contractor invoices, and zero-spend attestations.
- `product/` - agent execution logs, API usage records, screenshots, production dashboards, and demo video source captures.

Do not commit private customer data or financial exports to a public repository without redaction.
